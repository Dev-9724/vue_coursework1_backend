## 1. Project Overview

This repository contains the **Express.js back-end API** for the After School Class App.

The back-end:

- Connects to **MongoDB Atlas**
- Provides REST API endpoints to:
  - Retrieve all lessons
  - Submit a new order
  - Update lesson spaces when an order is placed
- Includes validation, middleware, logging and CORS settings  
- Deploys to **Render.com** (or AWS, depending on your setup)
